# 3개월 반복 측정 리포트 샘플

- PDF: `MPS_바이오밴딩_3개월성장리뷰_샘플.pdf` (2회차 · 3개월 리뷰)
- 실제 749건 v4 리포트는 변경하지 않았다.
- 가상 선수 1명의 4회 측정 이력으로 화면 전환을 보여준다. 점수, 단계 평균, 날짜, 관찰 내용, 선수 발언은 모두 가상이며 실제 결과로 사용하지 않는다.

## 표현 원칙

명칭은 `대한민국 유일 바이오밴딩기반 멘탈리포트`, 회차별 부제는 `첫 측정 · 나의 출발점`, `3개월 성장 리뷰`, `6개월 누적`, `9개월 누적`이다. 3개월 간격은 사용자 운영 계획을 반영한 것이며 검사 도구에 의해 검증된 권장 간격으로 주장하지 않는다.

1. **첫 측정:** 기준점과 다음 3개월의 행동 목표. 이전 기록이 없으므로 변화량은 `—`.
2. **두 번째:** 직전 원점수와 현재 원점수, 지난 목표와 실제 실행 기록, 다음 목표.
3. **세 번째 이후:** 직전 대비와 최초 대비를 구분하고 완료된 회차의 누적 추세만 표시. 미래 점수를 예상하거나 빈 회차를 0으로 채우지 않는다.

평균 비교는 현재 성장단계 평균을 사용한다. 성장단계가 바뀌면 집단도 바뀌므로 평균 격차의 변화를 개인의 향상으로 단정하지 않는다. 내 원점수 변화와 현재 비교집단 대비를 별도로 제시한다. 실제 집계는 단계·표본 수·집계일·참조 버전을 함께 보존한다.

점수의 작은 변동, 동일 유형의 유지, 유형의 변경을 성공·실패 또는 승급·하락으로 분류하지 않는다. 별도 측정 오차·재검사 신뢰도·변화 유의성 근거가 없으므로 통계적 유의성·치료 효과·프로그램 효과를 표시하지 않는다.

v3/v4의 유형별 선수, 8색 파스텔 유사도 막대, 5대 지표 레이더를 유지했다. P/R/I, 유형 경계와 유사도 계산식은 기존 방식을 그대로 적용했다. 샘플에서는 모든 회차가 A유형이지만 원점수는 달라지는 모습을 보여준다.

잉글랜드(흰 바탕 적십자), 벨기에, 네덜란드 국기는 마지막 페이지 푸터에 가로 6mm, 간격 2.5mm, 불투명도 72%로 표시했다. 국가기관·협회·클럽 로고, 인증·제휴·검증 문구는 붙이지 않았다.

## 실제 자료에 적용하기 전 필요한 연결

고유 선수 ID로 측정 이력을 연결하고 이름만으로 병합하지 않는다. 최소 저장 필드: 선수 ID, 측정일, 회차, 도구/문항/척도 버전, 응답자, 원점수, 성장단계, 성장단계 검수 상태, 비교집단 버전·표본 수·평균, 지난 목표와 실행 기록, 응답 환경. 이전 기록이 없거나 척도가 다르면 해당 변화량은 보류한다. 샘플에서 이 연결이 구현된 것으로 보지 않는다.

## 참고 사례

- [Pearson SSIS Progress Report: Teacher Form, 2쪽](https://www.pearsonclinical.ca/content/dam/school/global/clinical/ca/assets/ssis-sel/ssis-progress-report-sample.pdf): 반복 측정 시 최초 측정 대비와 직전 측정 대비를 분리하고 회차별 그래프·표를 제시하는 표현 구조를 참고했다. 이 자료는 사회성·행동 평가이며 MPS 검사와 동일하지 않다. 원문의 규준·신뢰구간·유의성 판정은 가져오지 않았다. 텍스트를 확인했으며 웹 PDF 스크린샷은 도구의 캐시 오류로 열리지 않았다.
- [Catapult Vector Core Longitudinal Report](https://core.catapultsports.com/hc/en-us/articles/7551850858639-Longitudinal-Report): 기간별 자료와 선택한 기준을 비교하는 스포츠 모니터링 사례. 부하·활동 리포트이며 3개월 멘탈 리포트 자체는 아니다.

두 사례는 구성 참고이며 MPS의 3개월 주기·유형·심리모델의 타당성 근거로 사용하지 않았다.

## 4페이지 개편

현재 샘플은 4페이지다. 기존 3페이지(지난 목표·다음 3개월 계획·국기)를 4페이지로 옮겼고, 새 3페이지에는 8대 세부지표의 성장단계 평균 대비·또래 만 나이 평균 대비와 직전 대비 상태를 넣었다. 샘플의 비교 평균은 모두 가상 예시이며 실제 평균으로 사용하지 않는다. 첫 회차는 이전 기록 없음, 마지막 회차는 향상·유지·저하가 함께 나타나도록 구성했다.
