# MPS 멘탈리포트

## 웹에서 업데이트

1. 첫 화면의 **엑셀 업로드 · 관리**를 누르고 관리자 비밀번호로 로그인합니다.
2. `입력 템플릿` 시트가 포함된 `.xlsx` 파일을 선택하고 **파일 검사**를 누릅니다.
3. 신규·중복·차트번호 변경·기존 값 변경·오류 건수를 확인합니다.
4. 기존 점수나 성장정보가 바뀐 경우 변경 확인 체크박스를 선택합니다.
5. **리포트에 반영**을 누릅니다. 서버에 저장된 후 리포트와 비교집단 평균을 다시 계산합니다.

파일은 최대 2MB, 5,000개 기록까지 지원합니다. 행 3의 열 이름으로 매핑하므로 열 순서를 바꿔도 됩니다. 오류 행이 있으면 전체 저장을 막습니다. 골연령 이상이나 성장단계 불일치는 기존 기준에 따라 검수 표시하고 관련 비교에서 제외합니다. 수식은 실행하지 않으며, 입력값 대신 수식이 있는 셀은 오류로 표시합니다.

선수명·성별·생년월일·측정일이 같으면 같은 측정으로 처리합니다. 식별 정보 자체를 수정하면 새 기록이 될 수 있으므로 업로드 전 확인하세요. 파일에 없는 기존 기록은 삭제하지 않습니다. 새 측정일은 이전 기록과 별도로 저장합니다.

## 구조

- `index.html`: 기존 4페이지 리포트. `/api/reports`를 불러와 렌더링합니다.
- `assets/upload.js`, `assets/upload.css`: 로그인·검사·반영·이력 UI.
- `api/session.js`: HttpOnly/SameSite 관리자 세션(8시간).
- `api/upload.js`: 서버 엑셀 검사 및 반영. 검사 서명과 저장 버전을 확인합니다.
- `lib/mental.mjs`: 기존 멘탈 분류·성장 계산 및 중복 검사.
- `lib/store.mjs`: Vercel private Blob 저장. 저장 전 스냅샷 백업, ETag 조건부 쓰기로 동시 변경을 보호합니다.
- `data/seed.json`: 전환 시점의 778건. 운영 데이터는 Blob이 기준이며 재배포로 초기화되지 않습니다.
- `scripts/build.mjs`: 웹 파일만 `public/`에 복사합니다. 원본 엑셀, 데이터 시드, 과거 CSV와 HTML은 정적 배포에서 제외합니다. 이전 주요 리포트 URL은 최신 화면으로 연결됩니다.

Vercel 환경 변수: `BLOB_READ_WRITE_TOKEN`, `ADMIN_PASSWORD`, `SESSION_SECRET`. 브라우저에 비밀키를 전달하지 않습니다. 조회는 기존과 같이 공개되어 있고 관리자 로그인은 업로드를 보호합니다. 업로드 이력은 최근 100회, 백업은 `mental/backups/`에 보관됩니다. 비밀번호 변경 시 세션을 모두 만료시키려면 `SESSION_SECRET`도 변경 후 재배포하세요.

## 개발 및 검증

`npm ci`, `npm test`, `npm run build`.

로컬 테스트는 `LOCAL_DATA_FILE`에 시드의 복사본 경로를 지정하고 `ADMIN_PASSWORD`와 `SESSION_SECRET`을 설정한 뒤 `npm run dev`로 실행합니다. 운영 Blob을 쓰지 않도록 별도 복사본을 사용하세요.

백업 복원은 관리자 작업입니다. 선택한 `mental/backups/` 스냅샷을 확인한 후 현재 상태도 백업하고, `mental/state.json`을 ETag 조건부 쓰기로 교체합니다. 복원 시 revision은 현재 값보다 증가시켜 기존 검사 결과를 무효화해야 합니다.
